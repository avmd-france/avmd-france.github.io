# AVMD-FRANCE Storefront

A responsive fashion storefront demo for AVMD-FRANCE.

## Included
- Premium editorial layout
- Men's and women's fashion sections
- Footwear section
- Real retailer-referenced prices researched on September 19, 2026
- Real editorial fashion photographs loaded from Unsplash
- Product filters, search, local cart, responsive mobile layout
- Source links on each product card
- GitHub Pages-ready static files

## Publish on GitHub Pages
Upload the contents of this folder to the root of `avmd-france.github.io`, commit the files, and GitHub Pages can serve `index.html`.

## Important catalog note
This is a storefront demo. Product names and prices are references from retailer listings available at research time. The editorial photographs are real fashion photos used for presentation and may not depict the exact retailer SKU. Retail prices and availability can change.
