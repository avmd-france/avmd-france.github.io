# AVMD-FRANCE — Storefront V3

This package includes a repaired logo, browser-tab favicon and locally stored fashion imagery, plus two customer contact sections.

## How to replace the example phone numbers

Open `config.js` and replace the numbers for `supportPhone` and `advicePhone` with your real business numbers. The +1 (202) 555-01xx numbers in this demo are **fictional examples**; they are not active business numbers. Set `demo: false` after replacing **both** numbers. This makes the phone links clickable.

## Upload to GitHub Pages

1. Extract this ZIP.
2. Upload **the files and assets directory inside the extracted folder**, not the ZIP file or the folder itself, to the root of `avmd-france.github.io`.
3. On GitHub, replace the prior files with the new versions, including `index.html`, `app.js`, `styles.css`, `data.js`, `config.js`, `favicon.ico`, `favicon-32.png`, `apple-touch-icon.png` and everything in `assets/`.
4. Commit and allow Pages time to deploy.
5. Refresh with Ctrl+F5 / Ctrl+Shift+R if the browser-tab icon is cached.

## Catalog caveat

Retailer names and price references are dated September 19, 2026. The photographs are real editorial imagery, stored locally for dependable display, and may not depict exact retailer SKUs. Prices/availability can change. Payment checkout is still only a demo. Product images are not guaranteed licensed for commercial use; obtain appropriate product photos and permissions before operating a real store.
